# Clempo

Marketing site for Clempo: the top 20 news stories of the day, written for kids aged 8 to 14.

## Files

- `index.html`: the page
- `styles.css`: all styling
- `clempo-logo.svg`: logo and browser tab icon

No build step. Upload the three files to the web root (for Hostinger, `public_html`).

## Colors

| Name | Hex | Use |
|---|---|---|
| Deep teal | `#0B2E36` | Headlines, buttons |
| Logo teal | `#14505C` | Card back, links |
| Logo orange | `#E39223` | Logo |
| Dark orange | `#C97A1A` | Small labels |
| Cream | `#F7F0DC` | Hero column |
| Grey | `#4A5A60` | Body text |

All corners use a 4px radius.
