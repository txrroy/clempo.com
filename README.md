# Clempo

Marketing site for Clempo: each day's most important world news, written for kids aged 8 to 14. The news itself is at https://clempo.news.

## Files

- `index.html`: the page
- `styles.css`: all styling
- `clempo-logo.svg`: logo and browser tab icon
- `fonts/`: Plus Jakarta Sans, hosted here (SIL Open Font License)

No build step. Upload everything to the web root (for Hostinger, `public_html`).

## Privacy rule

The page loads nothing from other domains and sets no cookies. Keep it that way: do not add analytics, embeds, or fonts from outside services. The site promises "no ads, no trackers, no cookies."
